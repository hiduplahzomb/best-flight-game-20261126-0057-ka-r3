Aurelia Wings — a 3D archipelago STOL flight simulator. Fly a bright twin-prop through golden gates over sunlit tropical islands at golden hour, then put it down on a short island runway. Five short sorties (mail rings, ridge slalom, mountain STOL, lighthouse cargo, crosswind final), a forgiving six-degree flight model with flaps and ground effect, fuel and hull to manage, and landing grades from S to B. Chase and cockpit cameras, a clean flight-sim HUD (compass tape, IAS/ALT tapes, pitch ladder, minimap, six-pack dials), keyboard and mouse controls. Runs offline in a desktop browser from its own files — no network, no library, its own tiny WebGL renderer.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and fly with the arrow keys (or WASD), Shift/Ctrl for throttle, F for flaps, G for gear, C for camera, M for missions, R to reset.
